About the Software Engineer & Founder

Welcome to the software engineering portfolio of Prateek Kumar, a full-stack developer, technical builder, and product founder based in Chandigarh, India. Currently pursuing a B.E. in Computer Science Engineering with a specialization in AI & Machine Learning at Chitkara University (2025-2029), I design responsive applications with modern JavaScript frameworks, high-performance backends, and robust real-time database management systems.

Featured Technical Projects & Core Architecture

MediQueue — Full-Stack Healthcare Platform

MediQueue is an ongoing comprehensive healthcare platform engineered using React.js, FastAPI, and Supabase. The system features a smart triage flow that seamlessly maps user-described symptoms to specialized verified medical professionals while handling real-time data synchronization, secure user authentication, and clinical record storage.

DevShare — Developer Social & Collaboration Space

DevShare is a dynamic social platform built using React.js, Node.js, Supabase, and Antigravity. It empowers engineers to showcase source builds, coordinate components in public, share programming ideas, and discover active technical career opportunities across an immersive developer community feed.

Gap to Growth — Intelligent Career Platform

Co-developed as a collaborative team project, Gap to Growth leverages React, Next.js, FastAPI, MongoDB, and TailwindCSS. The system applies natural language processing to parse professional resumes, calculate live industry skill-gap trends, map personalized learning paths, and conduct conversational AI-driven mock interviews.

Silent Hunt — Interactive Geography Quiz Game

Silent Hunt is an interactive location-based quiz application built entirely as a solo full-stack venture using vanilla HTML, CSS, and native JavaScript. It presents score-tracking logic and responsive UI modules guiding players to identify famous Chandigarh landmarks based on contextual hints.
